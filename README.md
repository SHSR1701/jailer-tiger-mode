# JAILER — Tiger Mode

A self-contained pixel arcade fan game inspired by *Jailer* (2023). Play as Tiger Muthuvel Pandian through three combat rounds, call in Narasimha and Mathew, and take on Varman.

## Play

Open `index.html` in a modern browser, or use the GitHub Pages link listed in this repository's About section. Tap **Enter Tiger Mode** to start and enable audio.

The game works without external assets or a build step. Touch controls are provided for phones. Rotate your phone for a compact landscape view.

| Action | Keyboard |
| --- | --- |
| Move | Left / Right or A / D |
| Jump | Space, W, or Up |
| Strike / combo | Hold J |
| Tiger Mode | K, once the swag meter is full |
| Narasimha: sniper support | Q |
| Mathew: bodyguard support | E |
| Pause / resume | P or Escape |

Narasimha marks the toughest visible enemy and fires three timed shots, then recharges for 18 seconds. Mathew enters the arena, fights nearby enemies, and provides seven seconds of cover, blocking up to three attacks; he recharges for 24 seconds. Calls with no targets aren't consumed. Both abilities refresh at the start of each round.

## Credits

This is an unofficial fan tribute, not a Sun Pictures release. Characters are inspired by *Jailer* (2023): Rajinikanth as Muthuvel Pandian, Shiva Rajkumar as Narasimha, Mohanlal as Mathew, and Vinayakan as Varman. The pixel art and arena gameplay were made for this game.

The soundtrack is a simplified instrumental chiptune loop of the hook from **Hukum – Thalaivar Alappara**, composed by Anirudh Ravichander. It does not contain the original recording or vocals.
